Built for High Availability & Zero DevOps Friction

No external dependencies like Postfix, Dovecot, MySQL, or Nginx required. RaHaMail handles the complete mail lifecycle natively.

Zero-CGO Single Binary

Compiled statically with embedded HTML/Tailwind templates and assets using //go:embed. Simply execute ./rahamail on any Linux/macOS/Windows machine or deploy in a lightweight Alpine Docker container.

Flexible Dual Storage Engine

Optimized SQLite with WAL Mode (Write-Ahead Logging) and concurrent readers for standalone nodes, or seamless enterprise clustering with external PostgreSQL.

Real-Time Reactive SSE

Powered by Server-Sent Events (SSE) hubs. Inbound emails instantly update webmail counters, live traffic spline charts, and streaming log monitors without CPU busy-wait loops or client polling.

Feature Matrix

Enterprise Features Out of the Box

Modular Multi-Page UI

Dedicated templates for Dashboard, Domain Management, Phishing Simulation, Live Logs, and System Settings. Includes native dark/light theme switching and custom modal dialogs.

Phishing Awareness Simulator

Train employees with built-in scenario templates (IT password reset, HR bonus, shipping notifications). Captures click metrics and provides interactive "Teachable Moment" education pages.

DKIM, SPF & DMARC Engine

Automatic RSA 2048-bit keypair generation with untruncated DNS TXT modals. Inbound verification engine validates SPF, DKIM, and enforces sender DMARC policies (p=reject/quarantine).

TOTP Two-Factor Auth

Pure-Go TOTP supporting Google Authenticator, Authy, and 1Password with standard otpauth:// URI export and bcrypt-hashed emergency recovery codes.

Developer REST API

Send transactional emails programmatically via POST /api/v1/send using Bearer token authentication (rhm_live_...). Manage and revoke API keys with fine-grained access.

Automated S3 Cloud Backup

Creates non-blocking SQLite database snapshots and compresses mail storage with client-side AES-256 GCM encryption before streaming to AWS S3, Cloudflare R2, Wasabi, or MinIO.

Security By Design

Fortified Against Modern Email Vectors

RaHaMail implements defense-in-depth protection across network protocols, HTML rendering engines, and physical disk storage.

Anti-SMTP Smuggling Protection

Enforces strict RFC 5321 CRLF delimiters via SmugglingReader, preventing CVE-2023-51764 and CVE-2023-51765 pipe bypasses.

Zero-XSS Webmail Sanitizer

Strips executable scripts, malicious iframes, inline event handlers (onerror, onclick), and javascript: protocol URIs from email bodies.

ClamAV & Rspamd Integration

Real-time socket scanning of attachments and inbound streams, automatically rejecting infected payloads with 554 5.7.1.

Inbound Trust Warning Banner

Classifies unknown external senders and displays interactive warning banners above the message reader with one-click "Trust & Add to Contacts" remediation.

Quick Start

Deploy RaHaMail in Minutes

Get a fully functioning mail server running with a single Docker command or standalone binary.

# Run RaHaMail via Docker Hub

docker run -d \
  --name rahamail \
  -p 25:25 \
  -p 587:587 \
  -p 143:143 \
  -p 993:993 \
  -p 8080:8080 \
  -v $(pwd)/data:/var/mail \
  -v $(pwd)/gomail.db:/app/gomail.db \
  --restart unless-stopped \
  coderhaqi/rahamail:v1.4.1

# Build and run directly from Go source

git clone https://github.com/coderhaqi/mail-server.git
cd mail-server
go build -o rahamail main.go
./rahamail

# Open your browser at http://localhost:8080 to complete setup
